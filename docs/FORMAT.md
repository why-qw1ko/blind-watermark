# BWM2 水印格式

BWM2 是 Web 与 uTools 版共同使用的图片盲水印格式。规范的目标是跨端一致、自动识别长度、可检测错误密码或损坏，不把乱码误报为成功。

> 密码只用于确定嵌入位置和扰码序列，不等同于经过安全审计的加密。盲水印也不能替代数字签名、版权登记或原始证据。

## 载荷

所有整数均为大端序，文本使用严格 UTF-8。

| 偏移 | 长度 | 内容 |
| --- | ---: | --- |
| 0 | 4 | ASCII `BWM2` |
| 4 | 4 | UTF-8 载荷字节数，无符号 32 位 |
| 8 | 4 | `SHA-256(payload)` 的前 4 字节 |
| 12 | N | UTF-8 文本 |

完整帧先按每字节最高位优先转换为 bit，再进行 7 次重复编码。

## 密码流与位置

1. 密码按原样编码为 UTF-8，区分大小写和前导零。
2. 使用 `SHA-256("BWM2/positions\0" + password)` 的前 16 字节初始化 `xoshiro128**`，4 个状态字按小端读取。
3. 使用该序列对全部可用系数执行 Fisher–Yates 洗牌，依次选择载荷所需位置。
4. 使用独立的 `SHA-256("BWM2/payload\0" + password)` 初始化第二个 `xoshiro128**` 序列；每个 32 位输出按最低位优先与编码 bit 异或。

位置流与载荷流必须使用不同的域字符串，不能合并。

## 图像变换

- 输入统一为 8 位 RGBA；Alpha 通道保持不变。
- 亮度：`Y = 0.299R + 0.587G + 0.114B`。
- 宽高以边缘复制补齐到 4 的倍数。
- 对 Y 通道执行两级正交 Haar DWT。
- 在第二级 LL 子带使用 QIM，量化步长为 40；量化整数绝对值的奇偶表示 bit。
- 极亮系数优先向下量化，极暗系数优先向上量化，避免 RGB 裁剪令 bit 丢失。
- 逆变换后以 `Math.round(newY - oldY)` 同量调整 RGB，并裁剪到 `[0, 255]`。
- 输出必须为无损 PNG；嵌入后立即从输出像素自检，失败时不得保存或宣告成功。

可用容量为补齐后 `ceil(originalWidth / 4) * ceil(originalHeight / 4)` bit。帧和重复编码开销已包含在容量计算中，最大文本载荷另限制为 4096 字节。

## 提取

提取端先读取固定的 `12 * 8 * 7 = 672` 个编码 bit，校验 magic 并获取载荷长度，再读取完整帧。以下任一条件都必须明确失败：

- magic 不匹配；
- 长度为 0、超过 4096 字节或超过图片容量；
- SHA-256 截断校验不匹配；
- UTF-8 解码失败。

## 兼容格式

- `DWT-QIM-JS-V1`：旧 uTools 格式。沿用 SHA-256 哈希链、手填编码 bit 长度和 7 次重复编码，没有 magic 或完整性校验。
- `python-blind-watermark-v1`：旧 Web 格式，由 `blind-watermark==0.4.4` 提供，只在 Web 兼容 API 中保留；密码为非负整数，结果无法验证真伪。

新增嵌入一律使用 BWM2。兼容提取只用于迁移历史文件。

## 黄金向量

- 密码 `p@ss`、容量 1024 的前 12 个位置：`199, 967, 400, 968, 96, 359, 36, 764, 858, 896, 927, 345`。
- 文本 `跨端 compat 🚀` 的帧（hex）：`42574d320000001295cb877ce8b7a8e7abaf20636f6d70617420f09f9a80`。
- 固定 192×192 RGBA 测试图嵌入后的原始像素 SHA-256：`baab42a57604ba2c686cac25d84bd51cf5341f87f35ebb7e5ce1d7b783c35dba`。
